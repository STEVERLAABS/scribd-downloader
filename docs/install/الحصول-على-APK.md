# دليل الحصول على ملف APK وتشغيل التطبيق على الهاتف

> الوضع الحقيقي: **بناء الـ APK على هذا الكمبيوتر مستحيل اليوم** لأن الإنترنت
> هنا لا يستطيع تحميل أدوات البناء (قِسناه مرات عدة: 0 بايت/ثانية، الاتصال يقطع).
> لذلك حضّرت لك طريقتين مضمونتين وخطواتهما حرفيًا أدناه.
> مسار المشروع: `C:\Users\Admin\Desktop\Scribd-Downloader-steVeR-Android`

## الطريقة ١ — موقع GitHub (الأسرع؛ لا تحتاج تثبيت أي برنامج)

ملفات المشروع جاهزة للرفع في مجلد سطح المكتب:
**`C:\Users\Admin\Desktop\GitHub-Upload`** — ٥٩ ملفًا فقط / ١٧٥ كيلوبايت.

الخطوات:

1. سجّل حسابًا مجانيًا على **github.com** (إن لم يكن لديك).
2. اضغط **New repository** → اسم مثل `scribd-downloader` → اختر **Public** → **Create repository**.
3. في صفحة المستودع الجديدة، اضغط رابط **uploading an existing file**.
4. افتح مجلد **GitHub-Upload**، حدد كل محتواه (Ctrl+A) وأسقطه في منطقة الرفع في المتصفح، ثم اضغط **Commit changes**.
5. متلألئ: يعمل تلقائيًا سير العمل **Build APK** (يوجد في `.github/workflows/build-apk.yml`) — يشغّل الاختبارات ويبني التطبيق.
6. انتظر حتى تظهر علامة ✔️ خضراء (٣–١٠ دقائق عادة).
7. اضغط العمل الأخضر → في الأسفل قسم **Artifacts** → نزّل **app-debug-apk** (≈ 5 ميجا).
8. فُكّ الضغط: ستجد **`app-debug.apk`**.

💡 يمكن تنفيذ كل الخطوات أعلاه **من الهاتف مباشرة** عبر متصفحه: الرفع، ثم
فتح الرابط، ثم تثبيت الملف — دون كمبيوتر أصلًا.

## الطريقة ٢ — بناء محلي (عند تحسن الإنترنت أو على جهاز آخر)

سكربت جاهز يجري كل شيء تلقائيًا: تنزيل JDK 17 + Gradle 8.11.1 + Android SDK
(٣٥)، قبول التراخيص، تشغيل اختبارات الوحدة، ثم نسخ الـ APK إلى سطح المكتب:

```powershell
powershell -ExecutionPolicy Bypass -File "C:\Users\Admin\Desktop\Scribd-Downloader-steVeR-Android\tools\build-apk-local.ps1"
```

التنزيلات قابلة للاستئناف: إن انقطع الاتصال أعِ تشغيل نفس الأمر فيكمل من حيث توقف.
الناتج: **`C:\Users\Admin\Desktop\ScribdDownloader-steVeR-debug.apk`**

بديل: كمبيوتر آخر عليه **Android Studio** → `File > Open` فولدر المشروع →
`Build > Build APK(s)` → الملف في `app\build\outputs\apk\debug\app-debug.apk`.

## نقل الـ APK وتثبيته على الهاتف

1. **النقل**: كابل USB (قص/لصق)، أو Google Drive، أو أرسل الملف لنفسك عبر WhatsApp/البريد.
2. **التثبيت**:
   - المس ملف `app-debug.apk` في الهاتف.
   - سيظهر إشعار «مصادر غير معروفة» → **الإعدادات/السماح لهذا المصدر** (سماحًا لبرنامج الملفات لديك).
   - عُد → **تثبيت (Install)** → **فتح (Open)**.
3. إن ظهر **Play Protect**: «تطبيق غير معروف» — اضغط **التثبيت على أي حال**
   (طبيعي خارج متجر Play).

---

## أول تجربة بعد التثبيت

1. افتح التطبيق → تبويب **Download** (تحميل).
2. لصق رابط سكربد مثل `scribd.com/document/12345/anything` أو `scribd.com/doc/12345`.
3. اضغط **⬇ Download**.
4. تتابع المراحل الأربع: تحليل → جمع → تنزيل → حفظ. إن ظهر تحقق Cloudflare،
   اتسع صندوق المحرك وأكمل الحل (ضغطة واحدة) — هنا يعود تلقائيًا.
5. سيجد PDF في «المسارات» / التطبيق في **المكتبة** يفتح ويعرض الملف ويمكن حذفه.

قائمة اختبارات مفصلة (١٤ مسارًا) في:
`docs\superpowers\testing\device-checklist.md`
